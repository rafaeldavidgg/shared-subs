Cómo funciona el cobro mensual

  1. Elige el mes de facturación arriba.
  2. Revisa cada suscripción y el importe por persona.
  3. Pulsa WhatsApp en la fila del contacto. El chat se abre con el mensaje listo, solo tienes que enviarlo.
  4. Marca Pagado cuando recibas la parte correspondiente.

Privacidad: los contactos y las plantillas solo se guardan en localStorage bajo sharedSubs.v1. El repositorio público incluye datos de ejemplo ficticios.
